OATH CLASSES — Image Assets
============================

Place the following images in this folder:

1. teacher.jpg
   - The main teacher/mentor photograph.
   - Used in the hero, mentor section, admin header, and chatbot avatar.
   - Recommended: square crop, good lighting, at least 500x500 pixels.

2. (Optional) topper-1.jpg, topper-2.jpg, ... topper-8.jpg
   - Topper / student photos for the "Our Toppers" section.
   - When adding, update the ToppersSection component to use them.

The website will automatically load teacher.jpg if present. If the image is not
available, a styled placeholder is shown automatically.
